# Лабораторная работа №1: Калькулятор (HTML/CSS)

## Цель работы
Освоить базовые принципы создания пользовательского интерфейса веб-страниц с использованием HTML и CSS. В рамках работы изучается структура HTML-документа, основы верстки элементов и применение стилей для их визуального оформления.

## Выполненные задачи

### 1. Разметка страницы (HTML)
Создана HTML-структура калькулятора с использованием семантических тегов:

- контейнер калькулятора
- поле вывода результата с ID "result"
- кнопки цифр (0-9) и операций
- специальные кнопки (C, +/-, %, =, .)

### 2. CSS-стилизация
Реализованы каскадные таблицы стилей с:

- стилями для различных типов кнопок
- эффектами наведения (hover) и нажатия (active)
- адаптивным дизайном
- центрированием элементов

## Индивидуальные доработки
По варианту выполнены следующие модификации:

1. **Изменение цветовой палитры**
2. **Сделана темная тема**
3. **Квадратные кнопки** вместо круглых
4. **Добавлена надпись** "ЛР выполнена ФИО" в нижней части
5. **Центрирование калькулятора** на странице
6. **Увеличение размера** окна вывода
7. **Кнопка GitHub** с ссылкой на репозиторий
8. **Переключатель тем** (светлая/темная)
9. **Сворачиваемые блоки** с выбором опций
10. **Добавлен фон**

## Как использовать
Открыть файл `index.html` в браузере.
